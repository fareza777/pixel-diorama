# Kebijakan Privasi — Pixel Diorama: World Builder

Terakhir diperbarui: 13 November 2026 · Pengembang: F7 Developer

Pixel Diorama: World Builder dapat dimainkan sepenuhnya offline. Mulai versi 1.3 game menampilkan iklan.

- **Game tidak mengumpulkan data pribadi.** Kemajuan game disimpan hanya di perangkat Anda. Jika fitur
  cadangan Android aktif, sistem Android dapat mencadangkan data aplikasi ke akun Google Anda sesuai
  pengaturan perangkat.
- **Iklan (Google AdMob).** Game menampilkan banner, iklan layar penuh sesekali, dan iklan berhadiah yang
  hanya diputar bila Anda memilihnya. Iklan disediakan oleh Google AdMob, yang dapat mengumpulkan dan
  memakai pengenal perangkat (misalnya ID iklan), alamat IP, serta data interaksi iklan untuk menayangkan
  dan mengukur iklan. Lihat kebijakan Google: https://policies.google.com/technologies/ads
- **Persetujuan.** Di wilayah yang mewajibkannya (misalnya EEA dan Inggris) game meminta persetujuan
  Anda melalui formulir Google. Anda dapat mengubahnya kapan saja di **Pengaturan → Ad privacy**.
  Anda juga dapat mereset atau menghapus ID iklan di pengaturan Android.
- **Internet** dipakai hanya untuk memuat iklan. Semua fitur game tetap berjalan tanpa internet.
- **Tanpa analitik dan tanpa pembelian dalam aplikasi.**
- **Izin getar** dipakai hanya untuk umpan balik sentuhan dan dapat dimatikan di Pengaturan game.
- **Berbagi** memakai lembar berbagi bawaan Android; game tidak mengirim apa pun sendiri.

Menghapus aplikasi atau memilih **Pengaturan → Hapus Data** akan menghapus seluruh data game.

Pertanyaan: hubungi F7 Developer melalui halaman pengembang di Google Play.
