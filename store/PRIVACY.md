# Kebijakan Privasi — Pixel Diorama: World Builder

Terakhir diperbarui: 11 November 2026 · Pengembang: F7 Developer

Pixel Diorama: World Builder adalah game offline.

- **Tidak ada data yang dikumpulkan.** Game tidak mengumpulkan, mengirim, atau membagikan data pribadi
  maupun data penggunaan.
- **Tanpa internet.** Aplikasi tidak meminta izin internet dan tidak terhubung ke server mana pun.
- **Tanpa iklan, analitik, atau pembelian dalam aplikasi.**
- **Penyimpanan lokal.** Kemajuan game disimpan hanya di perangkat Anda. Jika fitur cadangan Android
  aktif, sistem Android dapat mencadangkan data aplikasi ke akun Google Anda sesuai pengaturan perangkat.
- **Izin getar** dipakai hanya untuk umpan balik sentuhan dan dapat dimatikan di Pengaturan game.

Menghapus aplikasi atau memilih **Pengaturan → Hapus Data** akan menghapus seluruh data game.

Pertanyaan: hubungi F7 Developer melalui halaman pengembang di Google Play.
