# Pixel Diorama: World Builder

Offline premium Android game by **F7 Developer**. Build living miniature worlds rendered as 3D pixel
art: city building, villagers with daily AI routines, gathering, crafting, an economy, quests, random
events, achievements and long-term progression across seven island biomes.

Built with **three.js** and **Capacitor 8**. The renderer, day-night cycle, weather, lighting
materials and procedural audio are adapted from
[noxe-pixel-engine](https://github.com/danieljan-design/noxe-pixel-engine) (MIT, see
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)).

## Features

- **Pixel-art 3D diorama renderer**: low-res HDR pass, toon ramps, hard shadows, depth outlines, edge
  highlights, bloom, fog, colour grading, ordered-dither quantising, pixel-snapped orthographic camera.
- **Time and weather**: dawn/day/dusk/night with sun, moon, stars, Milky Way and aurora; clear, cloudy,
  rain (wet surfaces, splashes), storm (lightning + thunder), snow that settles, fog. Weather is rolled
  per biome; lamps and windows switch on at dusk.
- **Seven biomes**: Desa, Hutan, Pantai, Pegunungan, Gurun, Kota, Fantasi. Each has its own terrain
  generator, nature, house style, weather table, sky, ambience and resource bonus.
- **Building**: 31 building types in five categories, three upgrade levels, paint schemes (some unlocked
  by achievements), rotation, demolition with refund, footprint levelling, roads, landmarks.
- **Villagers**: names, traits, needs (food, energy, fun), mood, friendship, homes and jobs; schedule-driven
  AI (sleep, breakfast, work, lunch, leisure, chatting, festivals) with A* pathfinding; requests, gifts,
  dialogue. All villagers render through instanced meshes (about 10 draw calls for a whole town).
- **Economy**: worker-driven production, taxes scaled by happiness, storage caps, a market with
  supply-driven prices, crafting queues, the mayor's tool tiers.
- **Progression**: XP and 30 levels, 23-quest storyline, 27 achievements, 7-day daily reward streak,
  island unlocks, 10 random events, offline earnings (up to 8 hours).
- **Mobile**: touch camera (pan, pinch, twist, tilt, inertia, follow), immersive full screen, haptics,
  Android back button, autosave on a timer and when the app is paused, double-copy save with backup.
- **Adaptive performance**: device-based starting tier, frame-time monitoring with step-down/step-up,
  60 fps cap on high-refresh screens, adaptive shadows, bloom, reflections, lamps, grass and pixel size.
- **Fully offline**: no internet permission, no ads, no analytics, no external assets. Models, icons and
  sounds are generated by code.

## Project layout

```
src/engine/   ported noxe-pixel-engine: renderer, shaders, materials, environment, audio, kit
src/game/     data, island generation, models, people, pathfinding, world, game rules, camera, perf
src/ui/       DOM UI, pixel icons, build-menu thumbnails
src/platform.js  Capacitor storage, haptics and lifecycle
tools/        icon generator, keystore script, headless smoke test, device checks
android/      Capacitor Android project
store/        Play Store icon, listing draft, privacy policy
```

## Develop

Requirements: Node 20+, JDK 21, Android SDK (platform 36).

```bash
npm install
npm run dev            # http://localhost:5190 (desktop: drag, right-drag, wheel)
npm run build
npm run smoke          # headless Chrome run with screenshots in tools/shots/ (after build)
```

Debug handle in the browser console: `window.__pd` (app, game, world, ui).

## Android builds

```bash
npm run android:debug     # android/app/build/outputs/apk/debug/app-debug.apk
npm run android:release   # signed app-release.aab (Play) and app-release.apk
```

Release signing reads `android/keystore.properties`. Create an upload key with:

```powershell
powershell -ExecutionPolicy Bypass -File tools\make-keystore.ps1
```

The keystore lands in `keystore/` and the passwords in `android/keystore.properties`; both are
git-ignored. **Back them up.** Enrol in Play App Signing when you upload the first AAB.

After changing icons: `npm run icons` (writes Android mipmaps, splash screens and store icon).

Bump `versionCode` and `versionName` in `android/app/build.gradle` (and `VERSION` in `src/main.js`)
for each Play release.
